# yakuwari — script

```
METADATA
題材:        定年後、役割（呼び名）がなくなったとき、自分は何者なのか
承認済み題名: 定年後の月曜日、誰にも呼ばれないのはなぜか｜研究が見た理由
中心概念:    役割とは、まわりの人がその立場に寄せる「期待のまとまり」であり、呼び名は
             いつも向こう側から届くものだった。呼び名が止まるのは、まわりがその形を
             必要としなくなったからで、私が消えたからではない。離れることには
             真空と名残という実際の過程があり（Ebaugh）、同時に、考え方・好み・身につけた
             技は別の形で続く（Atchley）。呼び名がつく前からあったものは、ずっとそこにある。
柱:          E 時間と記憶
枠組み:      謎（冒頭の問い「私は、これから何と呼ばれるんだろう」を二つの研究で辿り、
             第4章で同じ朝に戻って問いの向きが変わる）。旅・列挙と混ぜない。

TYPO/出典（使用したもの）:
  ・Helen Rose Fuchs Ebaugh 1988『Becoming an Ex: The Process of Role Exit』
    （University of Chicago Press）
    ・本人が元カトリック修道女 → 社会学者・妻・母。1970年代の博士論文で元修道女を調査し、
      離れ方に共通の順番を見つけた
    ・対象を広げて計185人に聞き取り（離婚した人、元受刑者、断酒した人、元医師、
      元警察官、退職者、元修道女 ほか）
    ・四段階: first doubts / seeking alternatives / turning point / creating the ex-role
    ・古い役割と新しい自分のあいだの時期を、話し手たちが「真空 vacuum」と語った
    ・role residual（役割の名残、hangover identity）— 元の役割は消えずに残る
    ⚠ 台本で明言: Ebaugh が主に扱ったのは「自分で選んだ離脱」。定年（暦が決める）には
      最初の二段階がぴったり重ならない — 私の留保として言っている
  ・Robert C. Atchley 1989 "A Continuity Theory of Normal Aging"
    『The Gerontologist』29(2): 183–190
    ・内的継続性（考え方・好み・気質・技）/ 外的継続性（場所・人間関係・活動）
    ・継続性 ≠ 変わらないこと。過去とつながる形で変わる、適応の戦略
    ・Atchley が関わったオハイオ州（Oxford, OH）の縦断調査 — 千人超を二十年あまり
      （OLSAR / OLSAA。資料により 1,011人 / 1,200人超 と揺れるので「千人を超える」とだけ言う）
      → 多くの人が退職にうまく適応していた
    ・批判も台本で紹介: 男性の働き方を基準にしすぎ / 慢性疾患のある人が抜けている
  ・Ralph Linton 1936『The Study of Man』— 地位（status）と役割（role）を分けた。
    役割 = その立場にいる人に向けられる期待（社会学の標準的な定義として紹介）

⚠ 意図的に入れていないもの:
  ・「うつ病のリスクが40%上がる」— packaging で ⚠ 未検証。一字も書いていない
  ・Adams の三条件 / Hall 2018 / FIREA・Kauppi 2021 / 内閣府 — ep06 ashiba の素材
  ・「足場」という語 — ep06 の比喩。台本全体で一度も使っていない（「地面のない」で代用）
  ・友人づくり・人とのつながりの話 — ep06 の軸
  ・処方箋: 趣味を持つ / 地域活動 / ボランティア / 退職者クラブ / 生きがい探し — 全部外した
  ・社会情動的選択性理論 / Carstensen
  ・他のエピソードへの言及

サウンドスケープ: 朝の静かな家。遠くの鳥、壁の時計の秒針（最重要モチーフ）。
                九時を告げる小さな時報。第2章から低く柔らかな持続音。
                第3章後半で音をいったん細くする。第4章は冒頭と同じ朝の音に戻る。
                人の声・ざわめきは一度も入れない（ep06 との対比）。

章立て（cue の chapter ラベルは四つだけ）:
  第1章 — 月曜日の九時        C01〜C11  （入口・ひとり・朝の家）
  第2章 — 「元」になる人たち   C12〜C34  （Ebaugh: 185人・四段階・真空・名残・留保）
  第3章 — 役割という席        C35〜C62  （Atchley 継続性 → Linton 役割=期待 → 反転 → 限界）
  第4章 — 帰り道              C63〜C74  （同じ月曜日の朝・赤ペン・問いの向きが変わる）

ビジュアル提案（storyboard 向け）:
  第1章 — 平日の朝の和室／居間。窓から朝の斜光。壁掛け時計（秒針のクローズアップ）、
         ハンガーのネクタイ、机の名刺入れ。玄関の上がり框に揃えた革靴。人物はひとり。
  第2章 — 人の形をした像。体に 部長・夫・父・先輩 などの文字が立体の殻として重なっている。
         「真空」の場面では背景が抜け、像がわずかに浮く（地面のない空間）。
         名残 = 剥がれかけた殻の縁が薄く光として残る。
  第3章 — 殻が一枚ずつ自然に剥がれ落ちる（外から外されるのではなく、自ら離れる）。
         中から形の変わらない柔らかな光の芯が現れる。
         Linton の場面: 空いた椅子（席）に、期待の文字が浮いている。人が立ち去っても席は残る。
  第4章 — 第1章と同じ朝・同じ斜光。机の新聞と赤いペン。芯の光が、手の動きと重なる。
  ⚠ 「足場」「鉄パイプ」「建物のまわりの仮設構造」は使わない（ep06 の比喩）。
     殻は人物の体の上にあり、自分から剥がれる。
```
