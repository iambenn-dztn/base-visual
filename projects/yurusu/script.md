# yurusu — script

```
METADATA
題材:        許すことと忘れることは同じなのか — 研究は「許す・忘れる・仲直り」を三つに分けた
承認済み題名: 許すことと忘れることは同じなのか｜研究が分けた三つの言葉
中心概念:    許す・忘れる・仲直り（和解）は、研究の上では三つの別々のことである。
             許した人も、ほとんどの場合出来事を覚えている（Enright）。許しは相手がいなくても
             一人の中で起きうる（Enright）。そして許しは、「許せない」という重さを軽くする
             いくつもの道の一つにすぎない（Worthington & Scherer 2004）。
             だから、忘れられないことは許しに失敗したしるしではない。
             ⚠ 「許しなさい」とも「許さなくていい」とも勧めない。選ぶのは本人（Enright の書名
             『Forgiveness Is a Choice』）という立場に立つ。
柱:          E 時間と記憶
枠組み:      比較（三つの言葉を一つずつ分ける）。旅・年代記とは混ぜない。
            ※ 結果として「罪をほどく」効果は出るが、軸はあくまで三語の区別。

TYPO/出典（使用したもの）:
  ・Robert D. Enright（ウィスコンシン大学マディソン校）— 許しの定義:
    不当に傷つけた相手への恨み・否定的判断・冷たい態度をとる「権利」を自ら手放そうとすること。
    許し ≠ 大目に見る／言い訳する（condoning / excusing）
    許し ≠ 忘れる（許した人が出来事を忘れることはまれ。「新しいやり方で思い出す」）
    許し ≠ 和解（和解は二人の間の信頼の回復。許しは一人の中で起きる）
    押し込める・否認する・見ないようにする・忘れる → pseudoforgiveness（許しに似て非なるもの）
    許しは、ひどい扱いを受け続けることを受け入れる意味ではない。
  ・Enright『Forgiveness Is a Choice』(APA, 2001) — 書名のみ言及（「許しは選択である」）
  ・Enright Process Model — 二十の段階・四つの時期（uncovering / decision / work / deepening）。
    最初の時期は、自分の傷と怒りに気づくこと。
  ・Hebl & Enright (1993) "Forgiveness as a psychotherapeutic goal with elderly females"
    『Psychotherapy』30: 658–667 — 最初に発表された許しの介入研究。家族から理不尽な扱いを
    受けた高齢女性。⚠ 人数・期間は検証できなかったので読み上げない。
  ・Everett L. Worthington Jr.（バージニア・コモンウェルス大学）
    decisional forgiveness（決めるほうの許し）/ emotional forgiveness（気持ちのほうの許し）。
    REACH: Recall / Empathize / Altruistic gift / Commit / Hold on — 最初の一歩は「思い出す」。
  ・Worthington & Scherer (2004) "Forgiveness is an emotion-focused coping strategy..."
    『Psychology & Health』19(3): 385–405 — unforgiveness をストレス反応とみなす
    （恨み・苦さ・敵意・怒り・恐れ、反すうで重なる）。許しはそれを減らす「一つの」道であり、
    ほかに謝罪・償いを求める／法的な正義／受け入れて先へ進む、などがある。
  ・限界（必須・第4章で明言）: 心理学の一つの枠組みで、万人・万能の手順ではない / 深い傷ほど
    時間がかかり、許さないまま暮らす人もいる / この話は治療ではない → 専門家へ。

⚠ 意図的に入れていないもの:
   Worthington の母親が殺害された件（1995年大晦日〜1996年）。packaging で任意とされていた。
   入れない理由: (1) 4d に対して重すぎる。(2)「母を殺された人でさえ許した」という構図は、
   聞く人に「だからあなたも」という無言の圧をかける。この回の「勧めない」立場と正面から衝突する。
   ・報復／仕返しを「ほかの道」の例として挙げること（論文には含まれるが、この回では読み上げない）。
   ・傷の中身の描写。「ある名前」「三十年前のある人」のまま、一度も具体化しない。
   ・「忘れることは未熟な防衛機制」という言い方（packaging の文言）— 原文が確認できなかった。
     代わりに、確認できた pseudoforgiveness（押し込める・否認する・忘れる）の枠で言っている。
⚠ 中陰・四十九日・十王経は入れない（第1回で使い切っている）。
⚠ 冒頭の時間帯: 平日の朝・市役所の待合（EPISODES-PRODUCED-JA「空いている時間帯」の
   「sáng giờ hành chính」を使用）。夜・一人・座って静か、の型を避けている。

サウンドスケープ: 低く柔らかいドローン。役所の待合の気配（番号呼び出しの電子音、紙の音、
                遠い話し声）。第3章は外の音を抜いて、石を床に置く鈍い音だけを一度。
                第4章で待合の音が戻る。

ビジュアル提案（storyboard 向け）:
  第1章 — 市役所の待合。朝の斜光。長椅子、握られた番号札。人物の胸元に、暗く重い石の塊
          （不透明・PBR の岩肌）が重なって見える。
  第2章 — 三つの「言葉」を三つの空間として。①大目に見る（石に布をかぶせる＝違う）
          ②忘れる（石を箱に押し込める＝違う）。人影は石を抱えたまま部屋を移る。
  第3章 — ③仲直り（二人の人影と、一人の人影。両方とも同じ明るさ）。
          REACH の最初「思い出す」で、人影が石をまっすぐ見る。
          最後に、胸に抱えて引きずっていた石を、足もとの横へ下ろす。石は消えない。
  第4章 — 第1章と同じ待合。石は長椅子の足もとにある。人影が立って窓口へ歩いていく。
```
