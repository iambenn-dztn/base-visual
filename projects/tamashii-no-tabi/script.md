# tamashii-no-tabi — script

```
METADATA
題材:        四十九日の中陰と十王 — 魂はどこから来てどこへ行くのか
承認済み題名: 魂はどこから来てどこへ行くのか｜十王経が描く四十九日の旅
中心概念:    四十九日という日数は、インドの論書では「ほかにこう言う先生もいる」と添えられた
             少数意見にすぎなかった。それが千年以上かけて書き足され、いちばん恐れられる閻魔王
             の下に地蔵菩薩が置かれ、遺族が七日ごとに集まり直すための日程になった。
柱:          B 仏教の世界
枠組み:      旅（はじまりから終わりまで一本道。他の枠組みと混ぜない)

TYPO/出典（使用したもの）:
  ・『倶舎論』巻九 分別世品 — 中有の期間に四説。四十九日は「有餘師」＝少数説。
    競合説: 大德(不定)・世友(最長七日)・毘婆沙師(ごく短い＝部派の主流)
  ・『十王経』類（『預修十王生七経』) — 晩唐の中国で成立。十王はいるが、川・奪衣婆・鏡はない
  ・源信『往生要集』985年 — 八大地獄と六道は描くが、三途の川も十王も出てこない
  ・『地蔵菩薩発心因縁十王経』(略『地蔵十王経』·12世紀·日本で成立) — 三途の川、奪衣婆、
    浄玻璃の鏡、本地仏の一覧はここで揃う。三つの渡しの原文
    「所渡有三。一山水瀬。二江深淵。三有橋渡」
  ・『金光明経』 — 三途＝三悪道（餓鬼・畜生・地獄）の語源
  ・サンスクリット antarābhava（antarā＝中間の／bhava＝生存状態）＝中有・中陰
  ・十王の本地仏（閻魔王＝地蔵菩薩、泰山王＝薬師如来、五道転輪王＝阿弥陀如来ほか)
    — 伊藤瑞叡「十王」日本大百科全書（小学館)。本地仏の欄は日本で加わった部分
  ・死出の山が一週目、三途の川は二週目（二番目の王が「初江王」であることが構造的証拠)
  ・六道銭（六文銭) — 経典になく民間の習わし。六枚に固定したのは江戸期。
    渡し賃・六道の路銀・地蔵への賽銭と諸説（断定しない)。現在は火葬炉保護のため紙製
  ・宗派差: 浄土真宗は臨終と同時に極楽浄土へ往生すると説き、中陰の審判を立てない。
    上座部仏教は中有の存在そのものを認めない
  ・⭐ 締めの典拠: 浄土真宗本願寺派の公式説明「中陰法要は、亡き人への追善のためではなく、
    むしろ遺族自身が悲しみから立ち直っていくための機縁となる法要です」
  ・人類学的事実: 川を渡って向こう岸へ行くという死後観は、古代近東からギリシア神話まで
    世界各地にある（因果関係は主張しない)

⚠ 意図的に入れていないもの: 賽の河原 · 二十五菩薩 · 叫喚地獄幅 · 「800里」 ·
   ヴァイタラニー川を三途の川の起源とする説

サウンドスケープ: 低く長いドローン。遠い鈴の音。紙の擦れる音。水の流れ。蝋燭の芯がはぜる音。
                最終章は音を抜いて、部屋の静けさだけに戻す。

ビジュアル提案（storyboard 向け):
  第1章 — 暗い和室、位牌と蝋燭、ぼたもちの皿。手前に低い座卓。光は蝋燭一本だけ
  第2章 — 輪の構造。生と生のあいだに浮かぶ「すきま」。七つの区切りが刻まれた帯
  第3章 — 霧の中へ続く一本道。七つの門が遠ざかる。川、橋、衣を掛ける木、鏡、六つの行き先
  第4章 — 第1章とまったく同じ和室。蝋燭だけが短くなっている
```
